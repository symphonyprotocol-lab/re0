# RE0 全站交互原型

依据最新 `rebuild-proposal.md` 重构为三个相连的产品区域：官网、统一用户工作台、管理后台。保持现行电光蓝、海军蓝、纸白与浅薰衣草配色。无需依赖现有业务应用或数据库。

产品实体名称统一为 **Ree**（英文复数 Rees）；页面、导航、创建引导、对话、视频、统计、后台和提示文案使用新名称。现有 `/dots` 路由、内部字段及本地存储键继续兼容，以保留已有资料、头像和历史；旧账户中预置示例问题的名称只在显示时更新。

后台 `/admin/dots` 支持每页 20 / 50 / 100 条、上一页 / 下一页、紧凑页码和页码跳转；搜索名称、所有者、邮箱或编号，并按公开 / 私有 / 已下架筛选。筛选和每页条数变更回到第一页，条件写入 URL，刷新与前进 / 后退可恢复；越界页码自动收敛。表格只渲染当前页，内部滚动时固定表头，分页保持在表格外。`/admin/dots` 默认使用 1,200 条只读规模示例，取消进入 / 退出规模演示按钮及模式提示，与已有 Ree、所有者、审计和余额隔离；旧 `sample=scale` 链接会归一化为普通列表地址，保留搜索、筛选和页码。当前为浏览器内存筛选与分页，生产对接需使用服务端查询及分页。

后台列表点击 Ree 名称或“详情”进入 `/admin/dots/:id` 独立详情页，私有和已下架的 Ree 也可查看。沿用后台固定顶部导航，提供资料概览、知识来源、使用统计、管理记录四个 tab；展示所有者、分类标签、回答设置、示例问题、累计成功回答、知识就绪状态及计费拆分。知识来源列表展示元数据，支持名称 / 状态筛选和每页 20 条分页，点击名称可独立预览正文；不展示用户对话。管理记录只包含当前 Ree 的审计。下架 / 恢复复用原有填写原因和审计流程。返回入口保留来源列表的搜索、状态、每页条数和页码，也支持返回用户详情的“名下 Ree”。规模演示中的 Ree 可进入只读详情，不提供实际治理操作。

知识来源名称可点击进入 `/admin/dots/:reeId/sources/:sourceId` 独立只读审核预览。顶部面包屑“知识来源”返回当前 Ree 的来源列表，保留来源名称 / 状态筛选、来源页码及上一级 Ree 列表的筛选上下文。预览展示已保存的解析正文、音频转写文本、仓库文件或站点子页面，支持正文查找高亮；文件 / 子页面目录支持搜索及每页 30 项分页，选择与查找条件支持刷新恢复。管理员预览按当前 Ree 校验来源归属；缺失来源、处理中、失败、没有解析正文时显示对应状态，不补造文本、不抓取外部内容、不改动知识或扣费。

来源预览主顶栏提供“上一个来源 / 下一个来源”和当前筛选范围内的位置，沿用来源列表的名称、状态筛选及顺序，支持跨页连续审核。切换后返回列表会落在目标来源所在页，保留上一级 Ree 列表上下文；正文查找和仓库子文件选择随来源切换重置。首尾对应按钮禁用；来源已不符合当前筛选或不存在时，不跳出筛选范围。

## 启动

```sh
node rebuild-prototype/serve.mjs
```

打开 <http://localhost:4173/#/>。可设置 `PROTOTYPE_PORT=4174` 更换端口。所有路由均使用 Hash，可刷新并使用浏览器前进、后退。

新建 Ree 和对话具有各自的持久化 ID 与链接。

所有内页共用侧边栏：上方依次为工作台、发现 Ree、我的 Ree，下方为新建对话、搜索对话与快捷历史。移除产品导航中的「全部对话」菜单和历史底部的「查看全部对话」入口，历史直接从侧栏记录或独立「搜索对话」页面进入，不再弹窗。首次登录直接进入工作台；新建对话打开独立 `/talk` 页面并聚焦输入框，工作台只展示空间概览与管理内容。既有偏好字段、对话、Ree 和本地数据保留，提问、参与者选择、费用与引用继续共用原流程。

用户工作台与管理后台共用固定顶部导航布局。返回上一级统一通过顶部面包屑的可点击名称完成，不再增加独立的返回行；Ree 详情的功能 tab 与连续审核按钮并入主顶栏；其他页面按需保留二级功能导航。Ree 内页 tab 顺序为设置、知识管理、视频介绍、使用统计、对话，公开页入口独立放在右侧；同一位置显示可点击的层级路径，独立知识预览的上一篇 / 下一篇入口也在顶部。创建页的四步进度也集成在固定顶部栏。后台用户详情的功能标签移到顶部，使用 `?tab=credits` 等链接保存当前标签。内容区域按顶部栏的实际行数预留空间，手机端 Ree 工作台采用两层顶栏：上层保留返回、当前 Ree 名称和语言切换，下层功能菜单保留完整名称与独立触控间距，空间不足时横向滑动，切换页面后自动显示当前菜单。来源预览返回知识管理，其他 Ree 内页返回「我的 Ree」；内容按 112px 顶栏高度预留空间，避免遮挡。

发现页卡片使用 16:9 封面。有已生成介绍的 Ree 显示播放按钮与 15 秒时长，点击在适配屏幕的大尺寸弹窗中播放，卡片保留简介、来源、价格和提问入口；没有介绍时展示静态封面。一次只播放一个介绍，支持暂停、拖动进度和关闭，关闭弹窗后停止播放，隐藏标签页后暂停。此处复用本地 CSS / DOM 介绍动画，不加载或编码 MP4。

Ree 默认头像统一为“中心点 + 环形连接”的知识节点图形。新建和 Ree 设置均支持上传 JPG / PNG / WebP（5 MB 以内），在表单内缩放和调整裁剪位置；点击“使用此头像”后随创建 / 设置表单一起保存。取消表单保留原头像，可恢复默认；自定义头像同步用于封面、对话参与者、知识工作台及视频介绍。图片仅经浏览器裁剪为 512×512 后保存在本地演示数据中。

Ree 分类采用一个主分类（技术与 AI、设计与创作、商业与职场、学习与研究、专业知识、生活与兴趣，另有“其他知识”兜底）和最多三个细分标签。新建和设置支持推荐标签搜索、自定义标签、移除及去重，每个标签最多 20 个字符。既有标签不修改，缺失主分类时按首个可匹配标签推断；设置保存后使用明确选择的分类。发现页按主分类筛选，可与问题搜索组合，`?category=design&q=...` 可刷新和分享。公开页显示主分类及细分标签，分别链接分类筛选和标签搜索。

发现页支持大量 Ree 的分页浏览，默认每页 24 个，可切换到 48 / 96 个，并提供顶部前后翻页、底部紧凑页码和直接跳页。搜索、分类、排序均先应用于完整目录，再截取当前页；筛选变更重置到第一页，空结果和越界页码安全归位。搜索与筛选栏固定在全局导航下方，以 ResizeObserver 测量实际导航高度，兼容已登录工作区、未登录官网和手机；页面大标题不固定，避免占用列表空间。详情往返携带 sample、q、category、sort、size、page，返回时定位到结果工具栏。`discovery.js` 的 1,200 条演示数据仅存在内存，卡片显示「演示 Ree」，详情可独立刷新与浏览，但禁用加入真实对话；真实数据、头像、余额及已有记录不变。原型在内存中检索完整目录，仅渲染当前页卡片；正式接入数据服务时可沿用相同 URL 参数进行服务端分页。

Ree 详情页为纯信息展示。未登录时使用 1120px 最大宽度、24px 内边距的独立公开布局，顶部复用官网主导航（首页、发现 Ree、价格与购买、语言及登录 / 创建入口），内容区上方用普通文档流面包屑展示「返回发现 Ree → 当前 Ree 名称」，不再使用替代主导航的独立顶栏。手机端主导航分两行：第一行保留品牌、语言切换和登录，第二行完整展示首页、发现 Ree、价格与购买；导航处于正常布局内，吸顶后搜索栏根据实际顶栏高度定位，避免遮挡；已登录时在统一工作台右侧内容区打开，保留侧边栏和固定顶部面包屑「发现 Ree → Ree 名称」，复用其他工作区页面的宽度与边距。搜索、分类、排序通过 from 参数随卡片、封面及视频详情链接保留，返回或刷新后不丢失；返回路径仅接受发现页和已知筛选字段。登录回跳也保留此上下文。左侧展示已保存的头像、名称、简介、分类、创作者、视频介绍区域（有视频时保留保存的横竖比例，无视频时显示 16:9 默认视频占位）和静态话题示例；右侧展示知识就绪状态、累计成功回答、已启用且就绪的来源数量、好评率、成功回答价格及基本费／创作者查询费明细。仅保留「加入对话」作为使用该 Ree 的操作，沿用现有登录及新建／已有对话选择流程，实际提问统一在对话内页完成。公开详情不再渲染输入框、消息记录或可发送的问题按钮；已有 public:<dotId> 与创作者测试历史保持原样。来源只展示数量，不展示文件标题、目录或正文。发现页卡片底部保留价格，并展示累计成功回答数和好评率，移除文字「查看详情」；点击封面进入详情页并保留筛选上下文。缺少评价数据时显示「暂无评价」，不填入模拟百分比；既有评分字段继续兼容。视频仅保留静态标记，播放位于详情页。内置 RE0 产品助手恢复默认公开视频介绍；未生成视频的内置助手使用独立的默认预览副本，不覆盖已保存的作者草稿。其他自有 Ree 以已生成视频为准；没有视频时显示包含 Ree 头像、名称和「暂无视频介绍」的默认占位，不显示播放控件、不改动作者草稿。发现页与「我的 Ree」的无视频卡片封面复用同一默认占位，保持 16:9 比例；发现页点击进入详情，自有 Ree 点击进入工作台，测试 Ree 保留只读预览入口与公开 / 私有标记。详情页内嵌播放现有 15 秒介绍动画，提供播放／暂停、进度、重播和全屏／退出全屏控制（优先浏览器全屏，内嵌环境使用网页全屏）；全屏与页面内播放复用同一节点，退出时保留进度。旧 ?video=1 链接改为在详情页内播放，不再弹窗；Ree 工作台「视频介绍」页未生成视频时也复用同一默认占位，不展示播放器及镜头时间轴；保留生成脚本和草稿编辑入口，生成后恢复原有视频预览、时间轴与导出流程。累计值不标为 30 天统计；公开价格按 20 credits 基本费加创作者查询费展示，自己的提问仅收基本费另有说明。私有或下架 Ree 不渲染详情。页面和样式集中在 public-dot.js、public-dot.css，窄屏时详情与使用信息上下排列。

公开详情底部增加「相关 Rees」与「作者的其他 Rees」：相关度仅根据公开名称、简介、标签和分类计算，优先同主题，不读取知识正文或私有提示词；同作者优先使用账号 ID，兼容旧记录的作者标识。两组均排除当前 Ree、私有、已下架和重复记录，沿用发现页当前完整目录（含本次会话的批量公开 / 私有结果）。每个条目复用发现页的 16:9 视频封面；无视频时使用同一默认占位，封面和资料均可进入详情。两组始终上下排列，相关 Rees 在上、作者的其他 Rees 在下；桌面每组四列卡片，窄屏逐步改为两列和单列，每组每页 4 条并独立翻页；相关 Rees 仅保留相似度排序后的前 10 个，作者的其他 Rees 继续按完整公开列表分页，翻页只更新当前列表，不影响视频播放或另一组页码；无结果时保留明确空状态。条目链接保留原发现页的筛选和页码，返回时恢复上下文。

Ree 使用统计支持全部时间、天、周、月、自定义范围，按 UTC+8（Asia/Kuching）统计，周一为每周起点。两处页面共用日历弹层：按天点击日期、按周点击完整周行、按月点击月份；选定后自动更新统计，无需「查看」按钮。浏览年月不应用筛选，支持点击外部或 Escape 关闭，也可直接返回当前时段；移除单独的范围展示与前后箭头。按天展示小时趋势，按周 / 月展示每天趋势。成功回答、留存记录和查询收入随时段联动，来源数量明确为当前快照。缺少准确时间的旧记录仅计入全部时间，不从「今天」「刚刚」等描述推测日期。新成功回答在已有查询流水中保存 Ree、回答 ID 与准确时间，去重后统计，清空测试消息不会删除这些使用记录；流水不保存已清空的消息正文。Ree 汇总、趋势不受关键词搜索影响，搜索只筛选明细。自定义范围的日历顶部提供「最近 7 天 / 最近 30 天 / 最近 90 天」快捷选项，按 UTC+8 包含今天，点击立即应用并保留其他筛选条件；也可先选开始、再选结束，两次选择完成后自动应用；包含结束日期全天，支持同一天、跨月和跨年，重新选择过程中可点击外部或 Escape 取消。范围通过 `period=custom&start=YYYY-MM-DD&end=YYYY-MM-DD` 保存在链接与明细筛选中；较长范围的趋势自动按连续多天分组并标注间隔，最多展示 31 组。个人空间的累计回答明细共用同一套时间选择器与使用记录，按 Ree 汇总和逐条回答均保留时间筛选；来源列表维持当前快照。

文件夹按 Ree 独立保存。现有来源归入「未分组」，支持新建、重命名、删除文件夹，以及单条或跨页批量移动；移动弹窗也可直接新建目标文件夹。文件夹筛选可叠加关键词、类型和处理状态，链接通过 `?folder=<folderId>` 保留当前文件夹。当前文件夹中添加的新知识自动归入该文件夹。删除文件夹将其中的来源（含回收站记录）转回「未分组」，来源正文、处理状态和参与回答设置保持原值。文件夹与来源的归属关系保存在原有浏览器存储中，刷新后仍然有效；手机端使用可横向滚动的文件夹导航。

来源预览展示浏览器中已保存的内容。新上传的 TXT / Markdown 显示已保存原文（目前录入上限 10,000 字符，截断时提示）；PDF / 音频原文件可在本次上传会话查看，刷新后需要重新选择原文件。尚未接入真实 PDF / Word 解析、音频转写、网站抓取和 GitHub 同步，相应预览与规模数据明确标为示例。

## 重要交互规则

- 提问预留最高费用，按实际回答结算；没有相关知识则退回。输入「明天火星的天气」可体验不作答状态。
- 文件名或文本标题包含 `失败` / `fail` 可模拟处理失败与退款；可重试。
- 整站需已验证域名，私有 GitHub 仓库需连接授权。
- 只有有效 Plan 才能购买 Pack；Plan 取消后当期仍可用，已有 Pack 不失效。
- 只有收入余额可提现，最低 500,000 credits；KYC、税务、PayPal、7 天邮箱变更限制和单笔进行中限制均有演示门禁。
- 视频脚本 20 credits / 次；每个 Ree 首次导出免费，后续每次 50 credits；同内容、模板、颜色与比例缓存命中免费。取消导出释放预留额度，刷新后按中断处理。
- 原型按第 2.6 节采用 **4 镜头，3 + 4 + 5 + 3 = 15 秒**。文档接口表的「5 镜头」与此冲突，本原型以详细规格和数据模型的 4 镜头为准。
- 页头、页脚与侧栏的「全站导览」可跳转全部页面；新用户、余额不足、处理失败和重置场景的体验按钮已移除。
- 支持 Enter 发送、Shift+Enter 换行、中文输入法、⌘K / Ctrl+K 搜索、Escape 关闭、弹层焦点管理、手机抽屉及减少动态效果偏好。

## 原型边界

所有认证、AI、DNS、支付、KYC、PayPal 和视频导出都是本地模拟。不会连接真实服务、不上传文件、不保存完整 API Key、不生成真实 MP4。播放器用 CSS / DOM 时间轴演示设计，未安装 Remotion；实际实现 Remotion 时应按方案安装其官方技能。脚本 JSON 和交易 CSV 可真实下载。

数据存储在当前浏览器的 `re0-rebuild-prototype-v3` 中。使用演示资料，随时可重置。图表、模型调用与成本为明确标记的示例，不能当作真实运营数据。中英切换覆盖界面，知识内容保留原文。

源码分工：`app.js` 为知识 / 对话 / 计费核心交互；`suite.js` 为官网、Dashboard、后台与视频；`knowledge.js` 为来源管理与预览；`conversations.js` 为分页对话列表、搜索与批量整理。对应样式为 `styles.css`、`suite.css`、`knowledge.css`、`conversations.css`；`navigation.css` 统一固定顶部导航和可折叠侧栏布局。

## 人工 KYC 与提现（最新方案）

`/settings?tab=billing` 的身份验证改为平台人工审核：法定姓名、国家 / 地区、证件类型、号码后四位、有效期、证件照、手持证件自拍、W-9 / W-8BEN 类型及已提交声明。提供演示资料填充；提交后是 pending，不能自行验证通过，PayPal 绑定 / 修改和提现均以审核通过为门槛。拒绝意见和重新验证要求回显，重新提交保留历史。

后台 `/admin/kyc` 比对身份与证件，拒绝必填原因，通过记录审核人与时间。每次图片预览写入审计并在 60 秒后失效；通过后满 30 天清除原图引用并展示“原图已删除”。原型不连接私有 Blob 或签名服务：用户选择的图片仅存在当前页面内存，刷新即丢失，localStorage 只保存演示引用与表单元数据。真实私有存储、签名 URL、服务端鉴权与自动删除任务仍需生产实现。

提现分两步：待审核 → 批准后待人工打款 → 登记实付金额与 PayPal 转账 ID 后已打款。批准不直接支付且不解冻；实际金额与申请金额差额计为手续费；驳回 / 标记失败只解冻一次。pending 与 approved 均占用单笔进行中的额度门禁。无 PayPal API 或自动成功回调。


KYC 提交和查看资料统一进入 `/settings/identity`，使用统一工作台的页面框架。顶部面包屑的“余额与计费”可点击返回，随导航固定；三个资料区分为独立卡片，右侧展示审核流程和资料保留说明，手机端改为单列。提交后在原页面展示待人工审核与只读资料；资料、图片校验、拒绝后重提和后台审核沿用原流程。


后台 KYC 的“审核资料 / 查看记录”统一打开 `/admin/kyc/:id`，顶部面包屑“KYC 记录”可点击返回列表。身份信息汇总在照片上方，证件照和手持自拍在桌面端等宽并排，手机端单列；下方展示税务声明、审核历史与审核决定。两张预览分别记审计，60 秒后失效；重新获取只更新预览，不清空已填写的审核意见。历史记录和原图已删除的记录仍可打开，后者不再加载图片。


提现审核与人工打款登记改为独立路由，复用 KYC 详情页的固定顶部面包屑导航。待审核申请不能直接进入打款登记；批准后自动进入登记页，额度继续冻结。登记或驳回后保留只读详情，历史列表的“查看详情”可返回原历史列表。为页面评审补充两条独立模拟申请（待审核、待打款），不重置现有记录或个人账户余额。


视频介绍通过各 Ree 内页顶部的“视频介绍”进入；统一侧栏保留对话入口和历史，不再为创作者另设导航。


## 创作者个人空间的数据口径

工作台概览关注“Ree + 知识 + 收入”，新问题输入放在独立 `/talk` 页面；概览不重复展示总可用余额或无时间依据的回答趋势。

概览顶部四张卡片均为键盘可访问的链接。“我的 Ree”带 visibility=all，“知识来源”限定 scope=mine 并打开全部状态，“累计成功回答”限定成功作答、全部时间并按 Ree 汇总，“收入余额”限定 activity=income 并滚动到计费页的收支明细。筛选、查询、分页写入 URL，刷新与前进 / 后退可还原条件。

累计回答统计沿用 Ree 的既有累计数字；逐条记录仅来自实际留存的自有 Ree 成功回答，排除 noAnswer 和其他人的 Ree，并按消息去重。演示历史基数不补造正文或时间；已有正文缺失时间时明确显示“时间未记录”，新回答开始记录创建时间。

## 我的 Ree 排序

## 我的 Ree 的多选与批量公开 / 私有

列表每行和表头提供复选框，工具栏的「选择本页」也可在窄屏使用。本页选择与跨页选择分开计数，支持显式选中全部筛选结果及清空选择；翻页、排序和调整每页数量保留选择。更改搜索、公开状态筛选、切换演示目录 / 卡片视图、离开列表或刷新会清空选择，避免误改隐藏条目。

「设为公开 / 设为私有」会先展示实际变更数量、最多五个名称及其余数量；已是目标状态的不重复修改，已下架 Ree 在公开操作中跳过，管理员下架标记和原因保留。私有操作只改 public 字段，知识、视频、对话、计费与统计不变。确认时重新检查所有权、账户状态、记录是否仍存在及下架状态；真实修改统一保存一次，保存失败则恢复原值并保留选择重试。操作完成后更新列表与概览，清空选择，保留筛选与排序并修正越界页码。

普通页面中的 600 个测试 Ree 与原有记录共用选择及确认流程。确认弹窗分别列出真实 / 测试变更数量，并为测试名称添加标记。只有真实变更才调用保存，测试变更仅写入独立内存副本，不加入账户存储、不更改原始示例目录或余额；刷新后恢复。混合批次保存失败时同时回滚真实与测试变更，保留选择；确认时校验记录种类，避免测试 ID 被真实记录占用后误改真实数据。测试条目跨卡片 / 列表、排序和分页保留本次会话的可见性状态，详情仍为只读。

## 六类后台列表的千条规模演示

### 用户角色与认证（方案 2.7）

- 设置新增「角色与认证」：显示普通 / 认证 / 官方角色、五项门槛的当前数值与差距、500 字申请陈述、最多 3 个外部链接，以及审核结果、拒绝原因和角色变更历史。未达标不能提交；仅允许一笔待审申请；拒绝后等待 30 天。
- 后台新增第十页「认证申请」及独立审核页，展示提交时的指标快照、当前指标、申请陈述与链接、公开 Ree 直达。拒绝必须填写用户可见的原因。用户管理支持角色组合筛选、官方赋予 / 取消、认证撤销和审计；列表、分页和返回保留筛选。
- 公开页、发现卡片、对话参与者和回答署名的标识来自所有者当前角色，跨标签页同步。发现搜索仅在相关性同分时使用角色优先级，不覆盖相关性或明确的价格、回答数排序。
- 官方账号隐藏用户侧查询收入、KYC、收款绑定与提现入口，收入仍可由后台查看。角色操作不修改余额、定价、查询费、知识与对话。
- 认证规则位于 `user-role-domain.js` 的 `ROLE_REQUIREMENTS`；真实问答与反馈写入本地归属记录。旧回答总数、展示评分不作为有资格的证据。新增角色示例账号与 Ree 用于演示待审、通过、拒绝和官方状态，原账号数据保留。
- 入口：`/#/settings?tab=role`、`/#/admin/verifications`、`/#/admin/users?role=official`。这些为本地交互流程，没有接入生产接口。
