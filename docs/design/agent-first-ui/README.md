# re0 全新改版设计稿

`re0-redesign.html` 是 re0 全站改版的界面设计稿，与 [agent-first.md](../agent-first.md) 配套（对应文档 §1.1 和 §3.1）。它是一个自包含的单文件静态原型，所有数据都是示例数据，不连接 re0 的任何接口。

## 怎么打开

- 双击 `re0-redesign.html`，或在浏览器地址栏输入它的 `file://` 路径。
- 字体（Nunito 等）从 Google Fonts 加载，离线时会退回系统字体，版式不变。
- 页面里的中 / 英切换用浏览器本地存储（`re0-lang`）记住选择，只是在模拟线上行为。
- 线上版本（私有 artifact，内容相同）：https://claude.ai/artifact/G7T9XAhtyT1PW5F1tPhgNi

## 当前包含的内容（2026-11-26）

视觉方向已选定 **A「气泡」**：群聊气泡风格、圆角、珊瑚色主操作、Nunito 字体。B「星图」、C「贴纸」和第 1 轮的「索引卡」只作为放弃的方向留档。

顶部四个 tab：

## 怎么更新

- 每出一版新稿，用新的 HTML 整个覆盖 `re0-redesign.html`（文件名不变），并更新上面的表格（页面、状态、版本）。在 PR #270 的分支上提交一次，提交信息写明版本和改了哪些页。
- 设计稿里定下的产品决定同步到 `agent-first.md`（§1.1、§3.1、§13、§14），而不是只留在设计稿里；文档和设计稿不一致时，以文档里写明"已定"的为准，暂定项以设计稿最新一版为准。
- 不要手改这个 HTML：它由出稿的会话生成，改动应该在那边做，再覆盖进来。
