# 知识来源预处理：第三方成本结算

2026-11-03。最终费率版本 `provider-cost-v1` 取代此前的字符量 / 平台固定音频费率。知识管理与创建 Ree 的“粘贴文本”入口已移除，历史文本仍支持预览和重新处理，TXT / MD 上传保留。

## 结算规则

`credits = ceil((Firecrawl 实际美元成本 + embedding 实际美元成本 + 转写实际美元成本) / 0.0001)`。

所有调用先累计美元成本，最后统一取整一次，没有额外字符费、按文件固定费或最低处理费。明确免费的服务结算为 0。初始仅预留 1 credit 验证余额，属于可退额度，不是费用或总价上限；处理中的已确认成本会原子补足预留。

- **AI Gateway**：每次响应优先读取 `providerMetadata.gateway.cost`（包括明确的 0）；没有返回实际费用时，读取其公开 `/v1/models` 最新价目表，以当前模型对应的 token / 秒单价计算。目录缓存 60 秒。不使用存在阶梯价格或供应商差价的简单单价作为最终账单。
- **自定义 embedding**：严格匹配服务 API 地址、模型和账户配置，以供应商返回的实际输入 token 数计费。每次 `doEmbed` 分别记录，SDK 拆分多批不会丢失或覆盖费用。无按字符数估算的兜底。
- **语音转文字**：每段 `doGenerate` 单独记录，优先使用实际美元费用；否则按模型的实际 token 或音频秒数计价。支持输入 / 音频输入 / 输出 token 不同单价，以及供应商最低计费量、计费步长。不会用文件大小或转写文字量代替实际时长。响应没有时长时，依次取最后一个片段的结束时间、WAV 文件头记录的精确时长；仍未知时保留转写结果，该次费用记为未确认（不扣用户、不估算），在后台成本页待核对。
- **Firecrawl Parse**：只有本地读不了文字层的 PDF（扫描页、字体加载失败、乱码、文件打不开，或本地读取超出 60 秒 / 1000 页的预算，见 `lib/infra/connectors/pdf.ts`）整份送 Firecrawl；有可用文字层的 PDF 和全部 Word 都在本地解析，不调用 Firecrawl，也就没有 Firecrawl 收据。优先使用响应 `metadata.creditsUsed`；PDF 在该字段缺失时可按官方的每页 1 Firecrawl credit 规则使用 `metadata.numPages`，包含空白页。响应已返回但无法解析时，同样保留一条未确认收据再失败。只有请求本身失败（401 / 402 / 403 / 429 或网络错误）才让密钥进入冷却。以账户真实套餐支付金额除以包含的 Firecrawl credits 得到单价，支持不同密钥账户的独立价格。Firecrawl credits 与平台 credits 是不同单位。
- 目前网页、整站和 GitHub 使用本地连接器；没有实际调用 Firecrawl 时不收 Firecrawl 费用。Word、有文字层的 PDF 和 Markdown / TXT 本地解析同样没有解析服务费。它们仍按实际 embedding 成本结算。

例如 Firecrawl 实际消耗 30 credits，套餐单价 $0.001 / Firecrawl credit，embedding 额外花费 $0.00002，则总成本 $0.03002，最终收取 301 平台 credits。两次各 $0.00004 的 embedding 调用合计 $0.00008，只收取 1 credit。

## 本项目当前账户

用户确认 Firecrawl 为 Hobby 月付 $19；2026-11-03 官方价格页确认配额为每月 5,000 Firecrawl credits。因此当前单价为 `$19 / 5,000 = $0.0038 / Firecrawl credit`，即每个 Firecrawl credit 对应 38 平台 credits。该配置已写入本地 `.env.local`，并已按用户要求持久保存到后台数据库；运行时以数据库配置为准。本地环境文件不含新增凭据，不提交到 Git。超额 PAYG 的价格不同（该套餐为 $5 / 1,000 credits），如果改用超额额度，需要按实际采购价格更新对应账户费率，不将其假装成套餐内价格。

当前启用的 embedding 和转写均为 AI Gateway：`openai/text-embedding-3-small` 与 `openai/whisper-1`。用户提供的价目表分别为 $0.02 / 百万输入 token、$0.36 / 小时；两项报价也已存入后台，作为未返回单次实际费用时的可编辑计费依据；Gateway 返回的实际账单仍优先，不将报价写死到计费代码。

## 价格配置与依据

成本设置随服务配置维护：`/admin/firecrawl` 设置默认解析单价，并在 Key 编辑中按账号覆盖；`/admin/models` 在向量 / 转写模型编辑中设置成本，生成模型沿用原有配置内的价格字段。`/admin/pricing` 仅保留用户赠送与 Plan / Pack 售价、促销。服务地址、模型与账号由所属服务自动绑定，不再手工重复填写。AI Gateway 优先使用实际账单，其次使用配置的成本单价或目录报价。向量模型输入价格以 USD / 百万 tokens 编辑；转写支持按秒或按百万 tokens，并支持输出 / 音频输入 token 单价、最低计费数量与步长。

Firecrawl 操作为 `parse`，默认地址 `https://api.firecrawl.dev`；账户 `*` 匹配所有密钥，具体密钥 ID 优先。模型单价必须匹配完整 API 地址与模型，防止将同名模型在另一家代理的价格混用。`0` 仅用于已确认免费的服务；缺失配置绝不代表免费。

可通过 `.env.example` 中的 `PROVIDER_COST_RATES` 引导部署；后台保存后以数据库配置为准。服务配置及其成本在同一事务保存，并通过共享价格锁仅更新对应服务 / 模型 / 账号，不覆盖其他服务的单价；兼容的全量价格 API 仍有版本校验。所有改价写入审计记录。价格快照随调用保存，后续涨价不改写历史。

## 用量记录与失败处理

每次服务响应都会立即将服务、模型、用量、请求 ID（服务有返回时）、美元金额、价格来源与快照记录到来源的 `provider_usage` 活动。单价最多 12 位美元小数；供应商实际账单保留完整十进制精度（支持科学记数法），先用整数对齐精度汇总，最后统一转换为平台 credits。计费单位精确到百万分之一，避免浮点误差导致额外取整。

请求范围使用 AsyncLocalStorage 隔离，不会混入其他来源、聊天或免费知识画像生成的费用。embedding 模型切换导致的重复调用也按实际供应商成本记录。最终片段、就绪状态与账本结算在同一事务写入，结算额必须等于完整成本。

沿用处理失败全额退款的产品政策：失败时记录已发生的供应商成本作为平台支出，但不扣用户 credits；退款包含本轮补足的全部预留。唯一例外是余额不足（`insufficient_credits`）：已按实际成本补足进预留的部分照常结算扣除，只有超出余额的那一次调用由平台承担，否则 1 credit 余额即可反复触发付费解析而不付费。并行调用全部结束后再退款或结算，防止迟到响应修改已关闭预留。重试是新任务，以独立 run ID 隔离；超时旧任务不能结算或退款新任务。

自定义服务缺少单价时，在付费请求前停止（来源显示 `pricing_unavailable`，服务端日志写明缺少哪一项单价）；响应缺少用量且没有实际金额时，记录费用未确认状态，失败并退款，交由管理员核对，绝不回退到固定费用或将未知成本当作免费。

**部署步骤**：数据库没有价格配置且未设置 `PROVIDER_COST_RATES` 时，代码内置的唯一默认价是上文本项目 Firecrawl Hobby 账户的 `https://api.firecrawl.dev` · `parse` · `$0.0038 / Firecrawl credit`（`DEFAULT_PROVIDER_RATES`），因此新部署可直接处理需要 Firecrawl 的 PDF；后台首次保存任一供应商价格时会一并写入该默认价。更换 Firecrawl 套餐、使用自建 `FIRECRAWL_BASE_URL`，或启用非 AI Gateway 的 embedding / 转写端点时，必须在上线前于 `/admin/firecrawl`、`/admin/models` 配置对应单价（或在 `PROVIDER_COST_RATES` 中提供），否则这些来源会全部以 `pricing_unavailable` 失败。仓库中没有任何自定义 embedding / 转写端点的真实单价，不提供默认值。
